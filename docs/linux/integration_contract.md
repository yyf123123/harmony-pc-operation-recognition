# Linux 链路接口草案

状态：已核对 Native `pipeline.hpp`、WPS catalog 和特征 schema。Linux 采集/识别事件/历史请求已实现；下一步预测及操作—文件页接口仍需与对应负责人核对，不替代已有公开 C++ API。

当前 Python 入口为 `scripts.linux`，历史接口为 `collector.linux.history`。Native 分类结果的旧标签通过 catalog `legacy_label` 转成规范操作 ID；页级映射尚无实际实现。

## 共同关联键

- `app_id`、`app_version`、`label_schema_version`：应用和标签定义。
- `session_id`：完整采集或运行会话。
- `app_instance_id`：应用实例，包含进程启动身份，避免 PID 复用。
- `operation_instance_id`：一次真实或推定操作实例；同一标签可以有多个实例。
- `window_id`、`phase`、`start_monotonic_ns`、`end_monotonic_ns`：窗口与时间边界。
- `status`、`quality`、`error_code`：失败与观测覆盖。

跨进程可比较的单调时钟须来自同一主机时钟域；墙上时间仅作溯源。采样起止、动作起止和扫描耗时分别记录。

## 识别输入

使用现有模型规定的特征 schema 与 2048 维向量。输入不携带真实操作标签。采集原始 VMA 记录与特征计算保持可追溯关系；系统页大小由运行环境读取，不能固定写成 4096。

## 识别结果

包括事件/窗口 ID、应用实例、方法与模型版本、候选操作、分数、分数语义、时间与质量。类中心余弦相似度不自动解释为正确率或概率；与现有 Native 行为保持一致。

真值、UI 请求与识别结果分别保存。历史模块只接受配置的识别来源，不读取测试真值来修正结果。

## 历史与下一步预测

历史按应用实例和会话隔离，并有长度限制；事件 ID 用于去重，重复标签不等于重复事件。定义未知区间、乱序、进程重启与方法切换时的规则。

预测请求使用模型对应的操作词表；输出下一步候选、排序分数、预测模型和词表版本。没有已加载模型时返回未就绪。预测未来操作不作为已经发生的操作写回历史。

## 操作—文件页映射

映射至少包含应用/版本、操作 ID、上下文、文件身份及内容版本、文件页索引、页大小、支持样本数、访问频率、映射版本和来源会话。

映射是多对多关系。虚拟地址和 PFN 不作跨会话稳定键；文件内偏移与页索引的换算使用实际页大小。只有 VMA 级汇总时，不能输出伪造的精确页列表。

## 页面标签输出

输出页身份、标签或候选状态、依据操作、分数语义、生成时间、有效期、映射版本及身份确认状态。首轮以用户态观察输出为主。身份未确认或覆盖不足时输出未知；冷页标签须有独立的近期访问/观察范围与时间跨度依据。

标签输出不代表内核回收/预取已经生效。真实内核消费者、权限与 Apply 行为属于单独验收项。
