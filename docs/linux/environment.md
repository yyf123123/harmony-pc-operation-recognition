# Linux 运行与环境约束

- 在目标 Linux 环境运行 `/proc` 采集；macOS 可做现有 Native 构建、回放与离线推理。开始服务器或设备任务前，先读取该环境已有运行手册和禁令；本文件不授予未约定的服务器访问权限。
- 使用桌面用户运行 UI 自动化和本机采集入口。先验证目标进程 `stat/smaps/clear_refs` 权限；失败时明确停止。不默认 `sudo` 整个入口，避免 UI 变成 root 会话。权限分离服务尚未在本版本实现。
- 焦点默认适配依赖 `xdotool` 和 X11/Xwayland；原生 Wayland 的合成器接口未集成。不伪造焦点成功，也不靠应用启动状态证明实际焦点。
- 明确选择目标 PID 及所需子进程；不会用宽泛关键词匹配、`pkill` 或自动重启应用。进程启动身份改变时，丢弃当前样本并重新建立完整采样。
- `clear_refs` 会改变目标进程引用位，是采样协议的一部分；只在已有授权的测试目标上运行。不能同时运行其他清引用或页位采集器而不约定时序；与璟雯联调时先确定唯一的清位协调者。
- 使用测试文档副本，输出到唯一的外部运行目录；不覆盖旧采集、原始证据、模型或文档。命令 stdout/stderr 可能含文档内容，入口不将其持久化为证据文本。
- 此版本不自动清缓存、制造内存压力、加载内核模块、修改系统参数或接入回收/预取 Apply。后续任务依据用户已有授权与目标环境规则处理，不能因实现方便扩大实验范围。
- 默认 `5s × 2 baseline / 15s action / 5s post`，并记录 Linux capture profile。验证动作包含在 action 区间内；超时或窗口超长导致失败。修改时长须保留独立 profile，评估不混用。
- C 采集器通过 `sysconf` 使用目标系统页大小。VMA Referenced 是区域汇总，不提供精确页身份或访问列表；不能把它充作操作—文件页真值。
- 凭据由官方 GitHub 登录和本地凭据管理维护；不写入计划、环境规则、源码、日志或交接材料。本项经筛选源码和运行参数可公开发布到目标仓库；真实数据、SDK、闭源材料及凭据仍不公开。

## 本轮目标环境

- Mac：共用核心、回放、打包、已有 OpenHarmony SDK ARM64 交叉编译；不采集 Linux `/proc`。
- 鸿蒙内网：只能携入代码现场适配，不依赖远程连接或外传闭源材料/日志；按 [内网环境约束](../handoff/ENVIRONMENT.md) 和现有服务规范运行，使用三调用宿主入口及本地中文诊断。
- server-lbz：原有构建、自有测试子进程 `/proc`、取消/失败、持久运行器及私有 compact VMA 离线回放/打包验证范围保留。2026-11-01 用户要求在服务器独立运行 WPS 自动化：允许在本项目唯一新目录建立当前用户专用的 Xvfb、私有 D-Bus、窗口管理器和 WPS 会话，使用新生成的测试文档验证真实焦点、操作及采集；不接管或读取其他用户桌面。使用 `xvfb-run`/`xauth` 管理认证、禁用 X TCP，不使用 `-ac` 或 `xhost +`；配置与输出放在任务专用 XDG 目录，退出只清理本次创建且身份匹配的进程。不安装系统依赖、不 sudo、不改系统配置。离线仅传已核验的必要 compact TSV，不传慧京真实文档、标签或整个原始包；服务器新生成文档与真值另标独立来源。SSH 使用 BatchMode=yes、StrictHostKeyChecking=yes；主机密钥/权限错误停止，不关闭校验或修改 known_hosts。
- 慧京的 Linux 桌面：在她本人电脑的虚拟机，不能由本机远程连接；通过私下传输模型/代码包运行真实 WPS 操作与焦点检查，回传允许清单内报告。先三项再完整 18 类有限检查，正式扩采仍依当前状态门禁。
- fpga513：本轮不使用，无 WPS、无需 FPGA 硬件，不修改其项目或环境。
- Native 默认 Linux 焦点桥每次比对主进程的当前子孙树与显式授权 PID 集合；覆盖变化立即失效，不自动清理新 PID 的引用位。鸿蒙实际覆盖由已确认的焦点/进程接口提供。两种入口共享 clear_refs 协议，禁止并发清位。

本交付只开放完整受控窗口；短窗口实验不包含在源码或二进制中。
