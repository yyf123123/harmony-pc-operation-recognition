## 复现训练与显式加载

需要 Python 3.10+、NumPy 和已核验的 intake 目录。新入口先核对原始 ZIP SHA、190 个来源及标签、文档家族/会话隔离，并将训练向量与已核验的归档向量逐一比较，拒绝被改写的中间 CSV。

```sh
.venv/bin/python -m scripts.linux_train train \
  --intake /private/verified-intake \
  --output /private/NEW-model-run

.venv/bin/python -m scripts.linux_train verify \
  --model models/linux/wps_writer_pilot_v1

.venv/bin/python -m classification.predict \
  --model models/linux/wps_writer_pilot_v1/model.json \
  --schema wps.vma.feature.v1 \
  --vectors /private/new-windows/native_vectors.csv \
  --output /private/NEW-predictions.csv
```

`train` 输出 `model/` 参数以及私有 `training_manifest.json`、逐样本 `predictions.csv`；输出必须是新目录。当前真实训练运行保留在 `/Users/cvue/Documents/huawei_projects/model_runs/20261023-linux-wps-pilot-v1/`。参数和汇总指标另存本地仓库的独立目录；真实样本、明细和 ZIP 仍在 Git 外，没有执行包内脚本或连接设备。
