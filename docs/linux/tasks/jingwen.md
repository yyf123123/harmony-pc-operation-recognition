# 璟雯任务：操作—文件页映射与反推方法适配

## 目标

采集 Linux WPS 操作期间实际访问的文件页，构建可被下一步操作预测查询的映射，并将已有其他操作反推方法接入共同事件接口。

## 工作内容

1. 与 VMA 负责人统一应用、操作标签、会话、操作实例、窗口和时间基准；直接采用新仓库词表或显式版本映射，不能只靠中文名称关联。
2. 在目标 Linux 环境确认页级采集方法、权限、观测覆盖与开销，提供一个操作的原始访问证据。区分“被映射”“驻留”“缺页”与“被访问”；不能把 VMA 内所有页当成该操作访问的页。
3. 建立文件页身份：文件身份/版本、文件内页索引、页大小。虚拟地址与 PFN 只作当次运行证据，不能直接充当跨会话的稳定页键；文件被改写或替换后必须能失效。
4. 对同一操作跨文档、重复执行和不同会话统计访问频率、支持次数与上下文；输出多对多映射、映射版本、覆盖率与未观测原因。
5. 提供映射查询接口：给定应用版本、操作及上下文，返回页集合、访问频率和证据来源。文件身份无法确认或观测不完整时返回未知状态。
6. 与 VMA 负责人共同定义候选热页标签、有效期与失效规则。冷页判断需要明确观察范围与时间跨度；预测未命中本身不构成冷页证据。
7. 将自己负责的其他反推方法输出为共同的识别事件，与欣彤配合同步延迟、错误与证据字段。

## 交付

- 页级采集入口、依赖/权限说明与已知漏采范围。
- 原始页访问事件、带统计支持的操作—页映射及格式校验器。
- 映射查询最小示例，与预测输出衔接的用户态页标签示例。
- 至少一个真实操作的可复现验证；映射稳定性和过期规则说明。

## 验收

能从任意一条映射追溯到真实操作实例与窗口；跨进程重启仍能辨识同一文件页；文件更换时不复用旧映射。页命中率和覆盖率必须在独立会话上验证，不能仅在生成映射的同一批样本上自测。
