等待主要来自两次 5 秒基线、15 秒操作、5 秒后置及采样/校验开销。动作、检查与采集有嵌套，不能重复相加。该持久 Native 进程 RSS 从约 11.04 MiB 到 11.56 MiB（增加 532 KiB）；WPS 与辅助进程资源另计。各窗口之间有受控准备重置，尚未验收自然连续操作历史或小时级运行。

## 复现入口

先读取 [环境规则](environment.md)。已有初始化的私有测试 profile、真实 WPS、X11 依赖，以及任务目录中经过版本/SHA 核验的 `pywpsrpc 2.4.0` 时，可使用：

```sh
python3 -m scripts.linux_server_desktop \
  --profile-root /已有私有测试profile \
  --output-root /新的外部验收目录 \
  --native "$PWD/build/native/native/opsctl" --models "$PWD/models" \
  --app-version 实际WPS版本 --acceptance semantic \
  --automation-runtime /任务私有RPC运行库目录
```

语义预检全部通过后，`--acceptance full --order-seed 19` 运行一轮完整采集；`--acceptance input` 运行四项输入对照；`--acceptance soak --duration-minutes 20 --order-seed 47` 运行有界持久检查。它们是有限工程验收，不会开放正式配额。显式追加 `--model-profile linux-wps-writer-server-20261101-v2` 才使用候选；默认仍为旧小试 profile。输出包含私有原始侧录，不上传公开仓库。
